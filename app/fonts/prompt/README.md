# Prompt

Unmodified Prompt font files by Cadson Demak, from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/prompt

Licensed under SIL Open Font License 1.1; see OFL.txt.
Weights 300–900 cover the application's typography. Root layout uses next/font/local
so production builds do not depend on downloading fonts. Preloading is disabled
to avoid eagerly downloading all seven weights; the browser loads weights as needed.
